# Code of Conduct

## Our pledge

We want GameLog to be a welcoming, respectful, and technically constructive project. Contributors, maintainers, and users should be treated with dignity regardless of experience, identity, background, or communication style.

## Expected behavior

- Be respectful and assume good intent while discussing technical trade-offs.
- Give actionable feedback about code, documentation, and product behavior.
- Welcome corrections and explain the reasoning behind a change.
- Protect private information from devices, logs, screenshots, recordings, and crash reports.
- Focus on what is best for users and the project, not on winning an argument.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberately submitting malicious code, credentials, or device data.
- Disrupting discussion, review, issue tracking, or release work in bad faith.

## Enforcement

If a problem cannot be resolved in the public issue or pull request, contact the maintainer privately through the repository's GitHub profile. Security-sensitive reports should use the process in [SECURITY.md](SECURITY.md), not a public issue.

Maintainers may edit, close, or remove content and may temporarily or permanently restrict participation when necessary to keep the project safe and productive. Decisions will be documented with as much context as privacy and security allow.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
